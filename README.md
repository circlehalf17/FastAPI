## 추진배경
- 전국 창의문제 해결능력 경진대회의 예선에서 제공되고 있는 예선용 관리 웹 서비스는 기능적 결함이 많음.
- 대회 관리자 측에서 새로운 서비스 구축을 희망하고 있어 다시 구축하기로 결정


## 주요 모델 설명
- Q&A모델: 사용자가 대회와 관련된 문의를 하면 Q&A 챗봇이 자동으로 그에 맞는 답변 제공
- 문제생성모델: 관리자가 문제유형(수학/논리/상식/열린)과 난이도를 선택하면 그에 맞는 문제 생성
